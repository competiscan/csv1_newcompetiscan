HELP ABOUT ENHANCED SEARCH

Enhanced search consist of search options according to the selection made by you on general search page.
  1. Category : It provides the detail description of specific sector.
    e.g. Insurance contains categories such as:
    • Disability
    • Life
    • Health
  2. Sub Category : It provides the an additional description of specific category.
    e.g. The Life Category has Sub Categories such as:
    • Indexed
    • Term Life
    • UL
  3. The Category you choose will determine which Sub-Categories are available.
  4. You can make multiple selections by holding the Control (Ctrl) Key.
