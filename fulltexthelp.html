Full Text /OCR Search Tips

How to use Full Text: There are only 2 examples of when Full Text would be used:
·Entry ID#: "2007-04-09-07" Quotations must be used for search results
·If you want to search multiple entry id you can use a query like - Entry ID #: "2022-04-20-803","2019-07-15-99","2022-01-30-188"
Key words in a particular order/sequence for optimal results:

Example 1: "Instead of using a query in ocr or headline like - "variable universal life" or vul
Use a query like - "variable universal life" or "vul"
Example 2: Instead of using a query like - medicare and prescription
Use a query like - "medicare" and "prescription"
Example 3: Instead of a query like - annuities not fixed
Use a query like - "annuities" not "fixed"
Example 4: Instead of a query like - Health AND Savings NOT Account
Use a query like - "Health" AND "Savings" NOT "Account"
Example 5: Instead of a query like - blue* and arizona
Use a query like - "blue*" and "arizona"
Example 6: Instead of a query like - (Health and Savings) or Account
Use a query like - ("Health" and "Savings") or "Account"
Example 7: Instead of a query like - Health and Savings or Account and checking
Use a query like - ("Health" and "Savings") or ("Account" and "checking")
Note : Nested queries like - (("vision and dental") or ("dental and vision")) and (bundle or bundling or bonus or commission)) Will Not work.
Example 8: Instead of a query like - 'Private Fee For Service'
Instead of a query like - 'Private Fee For Service'
Use Double quotes instead of Single Quotes
Example 9: Do not form queries like - "Private Fee For Service", "Provider Relations"
- "genworth" + "LTC"
System only accepts operators like - and , or , not
Do not use symbols like - & , + , etc. for OCR search.
Example 10: Use and, or, not operators when performing multiple phrases
Instead of using a query like - "Unumprovident" "individual disability"
Use a query like - "Unumprovident" and "individual disability"
Example 11: Use the not operator only before the last phrase like - "Unumprovident" and "individual disability" and "Personal loan" not "home loan"
Do not use a query like - "Unumprovident" not "home loan" and "Personal loan" and "individual disability"
